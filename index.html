Agent Learning Roadmap

A focused guide to the concepts and skills behind capable AI agents.

Roadmap

Your learning journey

Follow six progressive stages, moving from essential developer tools to advanced Agent interfaces and projects.

  1. 01

    Stage 1

    Foundations

    Build the technical foundation needed to work effectively with Agent systems.

    • Python
    • CLI
    • Git
    • APIs
    • JSON
  2. 02

    Stage 2

    LLM Basics

    Understand language models in practice and how applications interact with them.

    • Tokens
    • Model usage
    • LLM APIs
    • Local models
  3. 03

    Stage 3

    Prompt & Tool Use

    Guide models clearly and connect them to useful external capabilities.

    • Prompt engineering
    • Few-shot prompting
    • Function calling
    • ReAct
  4. 04

    Stage 4

    Agent Engineering

    Turn individual model calls into practical workflows and reusable capabilities.

    • CLI Agents
    • MCP
    • Skills
    • Plugins
    • Subagents
  5. 05

    Stage 5

    Context & Multi-Agent

    Give Agents context, memory, coordination, and production-quality feedback loops.

    • RAG
    • Memory
    • Multi-Agent systems
    • Evaluation
    • Observability
  6. 06

    Stage 6

    Advanced Interfaces

    Apply Agents through richer interfaces and practical end-to-end projects.

    • Browser Use
    • Computer Use
    • Code Sandbox
    • Practical projects
